# @runium/plugin-tags

[![npm](https://img.shields.io/npm/v/@runium/plugin-tags)](https://www.npmjs.com/package/@runium/plugin-tags)
[![license](https://img.shields.io/npm/l/@runium/plugin-tags)](LICENSE)

Runium plugin, which adds tag support to differentiate the list of running tasks.

## Installation

```bash
npm install @runium/plugin-tags
```

or

```bash
yarn add @runium/plugin-tags
```
